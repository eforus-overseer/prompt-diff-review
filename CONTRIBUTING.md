# Contributing to Prompt Diff Review

Thanks for helping make this project useful and careful.

## Good places to start

- The first milestone in [`README.md`](README.md).
- Documentation, examples, schema review, and test fixtures.
- A small issue that explains the intended change and how to check it.

## Pull requests

1. Open an issue first for broad or breaking changes.
2. Keep a pull request focused and add a reproducible example or test where appropriate.
3. Explain assumptions, limitations, and how you checked the result.
4. Never include real credentials, private customer data, or unredacted incident details.

## Safe research

Only test applications and systems that you own or have explicit permission to assess. Keep attack-shaped examples inert and local. Do not add code that targets public services, harvests secrets, or runs destructive actions.

## Discussion

Please be respectful and assume good intent. Disagreement about labels and findings is welcome when it is specific, sourced, and open to correction.
